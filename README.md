# AbdElkader Muhammad Mansor | Portfolio

Personal portfolio website. Frontend Developer focused on Vue 3, Nuxt.js and TypeScript.

## Stack

Plain HTML, CSS and JavaScript. No build step required.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy (GitHub Pages)

1. Push this folder to a GitHub repository.
2. In the repository: **Settings → Pages → Source: Deploy from a branch**, pick `main` and `/ (root)`.
3. The site goes live at `https://<username>.github.io/<repo>/`.
